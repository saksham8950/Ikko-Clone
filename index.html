Execution rules

Rule 1 — One product architecture.
Do not create disposable “Board 1 / Board 2 / Board 3” builds. The custom carrier PCB is the actual product architecture.
Rule 2 — Do not buy yet.
Finish schematic → PCB layout → BOM cost → then order. Avoid random dev boards and incompatible displays.
Rule 3 — ₹25K working target.
₹20K is the aggressive minimum; ₹30K is the practical prototype ceiling. Do not use debt/EMI for the project.
Rule 4 — Display first.
Before PCB finalization, obtain the exact AMOLED datasheet, FPC pinout, lane count, voltage requirements, touch-controller details and mechanical dimensions.

CM5 I²S ──► CS43131 ──► 3.5mm │ └────► Class-D ──► Speaker USB-C ──► Charger/Power Path ──► 1S Li-Po │ MAX17048 gauge

What is intentionally excluded

Cellular: excluded. eSIM: excluded. Camera: excluded. Physical keyboard: excluded. Dedicated HDMI: excluded. Random development boards: excluded.

The USB-C port is intentionally the single external I/O hub for charging, USB data and DisplayPort monitor output.

Software plan

1 — Bring-up

Start with supported Android on CM5. Validate display, touch, Wi-Fi, Bluetooth, audio, battery, USB and DP.

2 — Device software

Build/adjust the device tree, kernel configuration and hardware integrations. Keep the base close to AOSP.

3 — Product UI

Build a touch-first launcher, compact settings, monitor/Desktop Mode and USB DAC Mode.

Do not start the custom OS before hardware bring-up. First make the board work with a known Android image. Then replace/customize the software stack.

Mechanical plan

First target

  • Approx. 90 × 75 × 12–14 mm
  • Design around the actual display and PCB
  • Battery on rear layer
  • USB-C on bottom/side depending on final board
  • 3.5mm only if it fits without compromising thickness

Optimization target

  • Approx. 86–90 × 72–75 × 10–12 mm
  • Remove debug connector
  • Shrink connectors/FPCs
  • Optimize battery placement
  • Reduce PCB dead space
Do not design the final enclosure now. The exact display FPC, carrier PCB and battery dimensions must be known first.

Budget control

₹20K — Aggressive

CM5 + wireless + economical display + basic PCB/audio/power. Minimal enclosure. Some parts may require careful sourcing.

₹25K — Recommended

Target configuration: CM5 4/32, suitable AMOLED, A8, integrated DAC, battery/power and first custom PCB.

₹30K — Comfortable prototype

Better display sourcing, PCB assembly allowance, enclosure prototype and spare/miscellaneous budget.

Next action — complete execution sequence

Follow these steps in order. Do not jump ahead. When one step is complete, move directly to the next step.

STEP 1 — Set up the project workspace
Create the project repository and folders from this checkbook. Put the locked product specification and architecture in the README. Create a simple decision log so component changes are recorded instead of repeatedly reconsidered.
STEP 2 — Collect CM5 engineering documentation
Download the official CM5 pinout, schematic/reference design, mechanical drawings and hardware design files. Identify every CM5 connector pin/interface that our carrier will use. Create a working pinout sheet for Display, USB-C, USB 3, I²S, PDM, I²C, GPIO, power and debug.
STEP 3 — Lock the exact display before PCB layout
Find the exact 4" AMOLED candidate. Obtain the complete datasheet and confirm physical dimensions, active area, FPC dimensions, connector pinout, MIPI DSI lane count, power rails, reset/enable signals, touch controller, touch interface and initialization requirements. Do not order the PCB until this information is available. If the candidate fails any requirement, select another display and repeat this step.
STEP 4 — Freeze the physical envelope
Using the real display dimensions, define the first PCB and enclosure envelope. Reserve space for the CM5, Wireless A8, battery, USB-C, 3.5mm jack, speaker, microphone and buttons. Set the first physical target around 90 × 75 × 12–14 mm rather than forcing the final thin size immediately.
STEP 5 — Create the complete KiCad schematic
Draw the actual carrier board, not a temporary development board. Connect the CM5 board-to-board connectors to the MIPI display/touch, Wireless A8, USB-C USB 3 + DP, battery charger/power path, fuel gauge, CS43131 DAC, speaker amplifier, PDM microphone, buttons, debug UART and test points. Use the official/reference circuits for high-speed USB/DP, power and DAC sections.
STEP 6 — Perform schematic review
Run ERC and manually review every power rail, connector pin, voltage level, reset line, interrupt, I²C address, audio clock/data line, USB-C configuration, USB 3 pair, DP lane and test point. Confirm every IC has the required decoupling/passives. Fix all errors before moving to PCB layout.
STEP 7 — Build and cost the BOM
Generate the complete BOM from the schematic. Get current prices for CM5, Wireless A8, exact AMOLED, battery, DAC, power ICs, USB-C connector, audio parts, connectors, PCB fabrication and assembly. Calculate the full landed prototype cost. Keep the target at ₹20K aggressive, ₹25K recommended and ₹30K maximum. If it exceeds ₹30K, reduce cost before ordering rather than improvising later.
STEP 8 — PCB layout
Start the 6-layer carrier PCB. Place the CM5 and high-speed interfaces first, then power, display, DAC/audio, wireless and connectors. Route MIPI DSI, USB 3 and DisplayPort according to impedance/length requirements. Keep analog audio away from noisy switching/high-speed areas. Complete ground planes, power distribution, thermal paths and test points.
STEP 9 — PCB design review
Run DRC and inspect the complete board. Verify connector orientation, mechanical clearances, CM5 mounting, display FPC access, USB-C placement, 3.5mm placement, battery clearance, antenna clearance and service/debug access. Check the 3D model against the intended enclosure envelope. Only proceed when the board passes electrical and mechanical review.
STEP 10 — Manufacture the first real carrier PCB
Generate Gerbers, drill files, BOM and pick-and-place files. Get multiple manufacturing/assembly quotes. Choose the supplier within the approved budget and order a small prototype quantity. Do not add new features at this stage. Rev A should implement the locked architecture only.
STEP 11 — Electrical bring-up
Before installing the CM5, inspect the assembled board and check for shorts. Verify charger/power-path behavior and every major voltage rail with a current-limited supply. Then install the CM5 and bring the board up carefully. Record every measurement and failure in the bring-up log.
STEP 12 — Bring up hardware one subsystem at a time
Use this order: power → CM5 boot → display → touch → Wi-Fi → Bluetooth → USB data → battery/fuel gauge → speaker/microphone → CS43131/3.5mm → USB-C DisplayPort monitor output. Do not debug multiple unknown subsystems simultaneously.
STEP 13 — Get Android running
Start with the supported CM5 Android image. Confirm the complete hardware works before modifying the OS. Then create/adjust the device configuration and integrate display, touch, audio, battery, USB and DP support into the Android build.
STEP 14 — Implement the two signature software modes
First implement Desktop/Monitor Mode: connect USB-C to a monitor and switch to an appropriate large-screen interface. Then implement USB DAC Mode: connect the device to a computer and expose the device audio path through USB while routing output through the CS43131/3.5mm path.
STEP 15 — Build the custom product UI
Create the touch-first launcher, compact settings, hardware controls, battery display, monitor mode controls, DAC mode controls and other product-specific UI. Keep the first version simple; polish comes after the core functions are stable.
STEP 16 — Mechanical prototype
Only after the assembled electronics are working, measure the actual PCB, display, battery, connectors and components. Create the first enclosure around those measurements. Start around 90 × 75 × 12–14 mm, then optimize toward the smaller target.
STEP 17 — Full-system validation
Test charging, battery runtime, thermal behavior, suspend/resume, USB-C DP stability, USB DAC operation, audio noise, Wi-Fi/Bluetooth reliability, touch, display, buttons and mechanical fit. Record failures and decide whether each requires software, enclosure or PCB revision.
STEP 18 — Rev B optimization
Only after the complete Rev A device works, reduce PCB dead space, remove unnecessary debug hardware, improve connector placement, optimize battery placement, reduce thickness and clean up the enclosure. Do not redesign the core architecture unless testing proves a change is necessary.
Immediate starting point: complete Steps 1–3 before buying anything significant. Your first hard engineering checkpoint is an exact display datasheet + CM5 documentation + a locked top-level schematic plan. Once those are complete, move to Step 4 rather than returning to product brainstorming.
